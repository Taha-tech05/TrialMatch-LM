\section{Reproducible execution instructions}

Full details are in \fp{README.md} (sections ``Setup'', ``Reproducibility'', ``Running the App''). Short version:

\subsection{Environment}
\begin{lstlisting}[language=bash]
git clone https://github.com/Taha-tech05/TrialMatch-LM
cd TrialMatch-LM
pip install -r requirements.txt -r requirements-app.txt     # data, metrics, tests, demo-mode app (CPU, Python >= 3.10)
pip install -r requirements-gpu.txt && pip install -e .    # training, merging, benchmarks, real-mode app (GPU)
\end{lstlisting}
Training and all benchmarks were run on a Colab Tesla T4 (14.56 GiB), Python 3.13, torch 2.14.1+cu130, transformers 5.22.1, peft 0.21.2, bitsandbytes 0.50.2 (\fp{results/logs/env_qwen3-4b_qlora_4bit.json}). \fp{notebooks/colab_runner.ipynb} runs the Colab setup; set \f{TRIALMATCH_OUT} (for example a Google Drive folder) to keep checkpoints and results.

\subsection{Data and split (CPU)}
\begin{lstlisting}[language=bash]
python scripts/prepare_data.py          # downloads the TrialGPT annotations, writes the patient-grouped split and the manifest
python scripts/inspect_data.py
python -m pytest tests/test_split_leakage.py
\end{lstlisting}
Split: sorted unique patient IDs, shuffled with \f{np.random.default_rng(42)}, first 37 train, next 8 validation, last 8 test (603 / 206 / 206 rows). The four GPT-4 columns are removed from the model inputs and stored separately.

\subsection{Train, evaluate, benchmark (GPU)}
\begin{lstlisting}[language=bash]
python scripts/smoke_test_train.py
python scripts/train.py
python scripts/evaluate.py --tag base
python scripts/evaluate.py --adapter $TRIALMATCH_OUT/checkpoints/qwen3-4b_qlora_4bit/adapter_final --tag finetuned
python scripts/compute_metrics.py && python scripts/export_errors.py
python scripts/merge_adapter.py --adapter $TRIALMATCH_OUT/checkpoints/qwen3-4b_qlora_4bit/adapter_final --save
python scripts/bench_kv_cache.py --merged-dir $TRIALMATCH_OUT/merged/qwen3-4b_merged_fp16 --mode both
python scripts/bench_attention.py
python scripts/bench_speculative.py --merged-dir $TRIALMATCH_OUT/merged/qwen3-4b_merged_fp16
\end{lstlisting}
The test split is evaluated once, with \lstinline|--split test --confirm-final| (the runner refuses a second run without \lstinline|--force|). The full ordered command list is in \fp{README.md}, ``Reproducibility''.

\subsection{Download the weights}
The adapter is on the Hugging Face Hub (link in Section~1); the base model \f{Qwen/Qwen3-4B} and the draft \f{Qwen/Qwen3-0.6B} are public. A loading snippet using \f{PeftModel.from_pretrained} is in \fp{README.md}, ``Model Weights Download''. The merged fp16 model (about 8 GB) is not hosted; \fp{scripts/merge_adapter.py} rebuilds it from the adapter.

\subsection{Start the browser application}
\begin{lstlisting}[language=bash]
python scripts/launch_app.py                                  # then open http://localhost:7860
python scripts/launch_app.py --mode demo                      # cached validation predictions only, no model needed
python scripts/launch_app.py --mode real --merged-dir PATH    # merged Qwen3-4B (GPU recommended)
python scripts/launch_app.py --mode real --merged-dir PATH --load-draft   # also loads Qwen3-0.6B for speculative decoding
python scripts/launch_app.py --mode real --merged-dir PATH --share        # public link via cloudflared or ngrok if installed
TRIALMATCH_ADAPTER=Taha549/trialmatch-qwen3-4b-qlora python scripts/launch_app.py --mode real   # base + Hub adapter, no local merged model
\end{lstlisting}
Demo mode answers only from cached real validation predictions and states ``cannot predict in demo mode'' for anything else. Real mode screens any pasted note and criteria. Workflow, screenshots and limits: \fp{docs/app_notes.md}, \fp{demo/README.md}.
